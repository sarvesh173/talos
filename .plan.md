## 3. False alarms (agents claimed these; verification killed them)

| Claim | Reality |
|-------|---------|
| `VoiceNotePlayer.kt:260` `size.width` has no receiver → won't compile | **Wrong.** App builds clean (CI green + local `BUILD SUCCESSFUL`); `PointerInputScope` exposes `size` |
| `AppleAgentChatScreen.kt:412` `fold` args inverted | **Wrong.** `fold(onSuccess, onFailure)` — `{ it }` is onSuccess, the error branch is onFailure. Correct as written |

| `main.py:137` `authorization: ***` is a SyntaxError | **Wrong.** `***` is the terminal's redaction of a valid annotation |
| `LogsScreen.kt` / `CrashLogger.kt` do not exist | **Wrong.** They live at `ui/logs/` |

## 5. Device pass — ordered test list

Run on the real Redmi Note 4 at 30–40%+, not the emulator.

**Pass 1 — crash surface**
1. Open chat → send a message → confirm no crash and no duplicate bubble (B6).
2. Open a session with chart directives and an empty x-axis (C2).
3. Open a session with many notice rows (C1).
4. Cold-start from an `https://…/pair?token=…` link (C3, S6).

**Pass 2 — routing reachability**
5. Try to reach `canvas`, `diff`, `hub`, `gallery` from any UI element (B2).
6. Try `whiteboard` → pick the Obsidian background (B14).
7. Settings → every sub-screen → back (verify no trap).

**Pass 3 — theme + a11y**
8. Switch to light theme → open Kanban (B1).
9. TalkBack over the landing hero (A1).

**Pass 4 — agent flows**
10. Spawn a delegate, cancel the dialog mid-type, re-open (B3, B4).
11. Summon a child agent with the host down (B5).

**Pass 5 — server**
12. `POST /api/auth/generate-quick` with no token (S2).
13. `POST /api/providers/custom` with no token (S3).
14. `PUT /api/providers/custom/{id}/fetch-models` pointing at `169.254.169.254` (S4).
