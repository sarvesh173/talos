### Step 4 — media (in progress)

The whole chain was broken, not just the UI:

```
app  upload bytes -> URL        ok (uploadMedia existed)
app  put URL in `attachments`   BROKEN (field never sent)
srv  store attachments          ok
srv  give them to the model     BROKEN (prompt was content + thought only)
```

So a "sent" photo was base64 text in `content`: stored, shown, and invisible to
the agent.

| Item | Status |
|------|--------|
| send paths carry attachments | fixed — `sendMessage` / `sendMessageTo` |
| attachments reach the model | fixed — `_build_prompt` lists the URLs |
| voice note real audio | fixed — uploads bytes, not a base64 blob |
| landing composer real sheet | fixed — uses `AttachmentSheet` + `ImageConfirmSheet` |
| fake sheet deleted | `AttachmentBottomSheet.kt` removed (4 of its 7 tiles were text claims) |
| tests | `tests/test_orchestrator_prompt.py`, 6 cases |
